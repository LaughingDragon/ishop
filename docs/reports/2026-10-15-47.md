## Summary

Cody's own Anthropic key is connected and works. It was saved on the new AI setup page at 17:23, and its test call succeeded. The page also handles renewal, since Anthropic keys last 30 days. It keeps a record of the key (never the key itself), reminds Cody 7 days, 2 days and on the day before it expires, and pauses only the AI helpers when the key stops working. The same "stopped working" check now covers the Gmail app password too.

## What was done

- **AI setup page** (/site-office/ai-setup, Cody and webmaster only):
  - **Storage:** one field for the key. It's saved to a private file outside the website and git, and read through the Key module, so the site's settings hold only the file path.
  - **Display:** never shown again, only "ends in …1234".
  - **Test call:** a tiny one (16 tokens on Claude Opus 5.5, a fraction of a cent) that also proves the account has credit. The page then says "Key works", or why not: key not accepted, no credit, too many requests, no connection.
  - **Buttons:** Test the saved key, and Remove key.
- **What the site records:** saved on; expires on (the date Anthropic shows, or 30 days by default); the last 4 characters; the last successful call; the last error; whether AI is paused and why; the dates of past renewals. Never the key.
- **Renewal (same page):**
  - **Steps:** create a new key named "Reseller Matrix YYYY-MM", paste it, and enter its expiry date if Anthropic shows one.
  - **Test first:** the new key is tested before anything changes. On success the site switches over at once and reminds Cody to delete the old key at Anthropic. A failed test changes nothing: the old key keeps working. Cody can renew early.
- **Reminders:**
  - "Needs you now" shows "Your AI key expires in N days" from 7 days out, with a **Renew** button.
  - An email goes to Cody at 7 days, 2 days and on the day. It's checked daily at 7:05 a.m. Pacific, and each reminder is sent only once. If the server was off on a reminder day, only the most urgent one is sent.
- **When AI stops working:**
  - **Pauses AI:** Anthropic refusing the key, the account running out of credit, or the expiry date passing. "Needs you now" shows it right away, with Renew. Every other feature keeps working, and items and photos still save.
  - **Only noted:** a rate limit or a lost connection doesn't pause AI.
  - **Queue:** "Write my listing" requests will be queued while AI is paused, and run once the key is renewed. That part is built with the listing helper itself (next proposal).
- **Gmail:** the site now notices when Gmail refuses the login (a changed or revoked app password). "Needs you now" says "Email stopped working: renew the app password", with a button to the mail setup page. Only a yes/no is kept, not the error text, which names the account.
- **status.json:** a new "ai" section (configured, expires on, days left, last success, paused, renewal dates; no key material), plus "problem" under mail.
- **Cody's existing key** (saved before the record existed) was adopted: last 4 characters and a default expiry of Nov 14. Cody can enter the real date when he next renews.
- **New module ishop_ai**, using Anthropic's official PHP SDK. It gave logged-out visitors no permissions.
