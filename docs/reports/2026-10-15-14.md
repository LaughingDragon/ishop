- Commits: 235ada5

## Summary

Items exist now. There are five taxonomies; an Item content type with every approved field, including the review's gaps; and an "Item photo" media type in private files. Photos are prepared once on upload: HEIC becomes JPEG, photos are turned upright, location data is stripped, and the long edge is capped at 2560 px.

One problem was found and fixed during testing. Installing Media quietly let anonymous visitors download private photos. It's fixed, and a guard now stops it happening again.

## What was done

- **Taxonomies:**
  - Condition: 6 terms.
  - Category: 13 top-level terms.
  - Brand: empty, grows as typed.
  - Storage location: **Game room > Table > Table A / B / C** and **Game room > Overflow**, from Cody via Liam. New items default to **Table**.
  - Purchase source: Amazon.
- **Item:**
  - Fields: title, photos, description, flaws, brand, size, color, category, condition, quantity (default 1), status (Draft / Ready / Listed / Sold / Returned to Amazon / Donated / Kept; default Draft), asking price, AI price range, original price, cost paid, purchase date, purchase source, order ID, ASIN, return-by, weight (oz), package length × width × height (in), storage location, internal notes and show in shop. No Crosslister ID.
  - The form is grouped as Listing (open), Prices (open), Shipping, Money and purchase, and Storage and notes.
  - The title is limited to 80 characters, with a live counter that warns past 60 (Grailed) and 70 (Vinted). The description counter goes to 1000.
  - The item page starts with a **ready-to-list checklist**: photo, real title, description, category, condition and price.
- **Photos:**
  - Media type "Item photo", stored in `private://items/YYYY-MM/`, accepting jpg, png, webp, heic and heif up to 32 MB.
  - The new `ishop_items` module prepares each new photo with ImageMagick 7:
    - HEIC is detected by the file's contents and converted to JPEG at quality 88;
    - the photo is turned upright;
    - **all metadata is stripped** (GPS, camera);
    - the long edge is capped at 2560 px.
  - Drupal's image toolkit is now ImageMagick (drupal/imagemagick 5.0.1). Without it, image fields reject HEIC before conversion can happen. Thumbnails come out as WebP.
  - ImageMagick's `policy.xml` allows only JPEG, PNG, WebP and HEIC/HEIF, with no external programs; the resource limits are unchanged.
- **Permission problem found and fixed:**
  - Installing core Media granted **anonymous visitors "view media"**, so a private photo URL downloaded without logging in.
  - Only the synthetic test image existed. The Apache log shows only this VM's own test requests.
  - Revoked within minutes; anonymous visitors now get 403.
  - **New guard:** after any module install, the site office module revokes anything granted to anonymous visitors and logs it. Tested by installing and removing `ban`.
- **Backups:** `private/styles` (regenerable thumbnails) is also left out of the nightly tarball.
