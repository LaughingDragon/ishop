## What was done

  - Removed: Powered by Drupal, the second site-branding block, and the account menu (its Log out duplicated the header button).

- **Site office markup:**
  - Navigation: `so-nav` tabs, with `aria-current="page"` on the current page.
  - Board: an `so-sign` summary with `so-stat` tiles (percent of the plan built, open punch items).
  - Status board: `so-pill` statuses, `so-progress` bars, and every table in `so-table-wrap`.
  - Punch list: open items as an `so-callout--warn` with a count diamond and "Answer it" `button--hazard` links.
  - Reports: listed as `so-card` cards with `so-date` tiles.
  - Report pages: an `so-report` article with the band (kicker, `h1`, facts), a section per part, a `so-report__blockers` panel only when there are real blockers, and `so-hashes` commit chips. The theme's page title block is hidden there, so each page has one `h1`.
  - Table captions dropped (the theme styles captions as big headings; each table already has its `h2`).
