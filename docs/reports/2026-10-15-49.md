## Summary

Cody can now tap **Write my listing** on any item, or tick "Also write the listing with AI" when adding one. About a minute later the item page shows the AI's suggestions beside what the item has now. Each one has a tick box, so nothing changes until he chooses. **Why this price** shows what the web search actually found, with links to the sources. The first real run, on Cody's puzzle, took 45 seconds and cost $0.41, and the draft is waiting for his review (item 229).

## What was done

- **Ported from the old crosslister, word for word:** the prompt and the 13 listing fields: title, description, category, condition, flaws, brand, size, color, price range, suggested price, research notes, sources.
- **How a run works:**
  - up to 8 photos, at 1568 px;
  - web search (at most 5 searches), with eBay sold listings checked first;
  - an automatic photo-only retry if the search request fails;
  - research notes and sources are cleared if no search really returned results, so a guess is never shown as market data.
  - It runs on Claude Opus 5.5 (decision 226), with Anthropic's server-side fallback if the model declines.
- **Runs happen in the background:** a one-minute timer works through the queue.
  - **Held, with the reason on the item page:** while AI is paused (expired or refused key, or no credit), and while this month's AI spend is at the **$25 cap** (decision 226). They go ahead once renewed, or next month.
  - **A refused key or empty account** found mid-run pauses AI straight away (renewal workflow); the run waits for the renewed key.
  - **Everything else keeps working**, and items and photos still save.
- **Cody reviews everything:**
  - **The AI listing helper panel** on the item page shows each suggestion beside the current value.
  - **Ticked by default:** only fields that are empty, or still have the placeholder "New item …" title.
  - **Matching:** condition must be one of the site's six. The category is matched to the site's categories, and if there's no match it says "pick one yourself". A new brand is added to the brand list.
  - **Applying:** "Use the ticked suggestions" saves them as a new revision ("AI suggestion used: …"). "Dismiss" changes nothing.
- **Why this price:** the suggested price and range, the research note and the source links. It stays on the item.
- **"Needs you now":** "AI draft ready: … Review".
- **Usage per run is recorded:** tokens, searches and cost, priced from Anthropic's price list (checked today: $4 / $20 per million tokens, $10 per 1,000 searches). The next step puts the per-item cost on the Money page.
