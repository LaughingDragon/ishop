## What was done

- **New module `ishop_inbox`**, separate so it can be switched off or removed on its own.
- **Read-only by construction.** PHP 8.4 has no IMAP extension, so the site has a small IMAP client of its own. It can send only CAPABILITY, LOGIN, EXAMINE (opens the mailbox read-only), UID SEARCH, UID FETCH with BODY.PEEK (doesn't mark mail read) and LOGOUT. STORE, COPY, MOVE, APPEND, EXPUNGE and DELETE aren't possible, and a unit test proves they are refused. Nothing in the mailbox is sent, deleted, moved or marked. "Processed" is recorded on the site's side (one row per email), so each email is read once.
- **Only the seven marketplaces, and only real ones.** The Gmail search covers the marketplaces' domains and skips Promotions, Social and Forums. An email counts only if Gmail's own Authentication-Results say DKIM or DMARC passed for that marketplace's domain, so a forged "You sold it!" is ignored. For Facebook, only Marketplace mail counts.
- **Reading:** keyword rules for sold, offer, ship-by, label, shipping delay, return requested, case/dispute and payout (a return or case outranks the sale it's about). The site reads out only the item title, a price, a ship-by date and the listing's ID from its link (tracked links decoded). It never reads the buyer's name or address.
- **Matching to an item:** first by the listing ID in the email's links compared with the saved listing link (exact). Otherwise by title words, and only when one listing clearly wins; a near tie is no match, and Cody gets "Find it".
- **What it does by itself:** saves a real ship-by date on a sale (replacing the estimate), and attaches a PDF label to its sale. Labels are private files named label-platform-date.pdf, with no buyer details in the name, and are deleted after delivery like Part A's.
- **What waits for Cody:** a sale. Row: "Mercari email: X sold for $30.00. Mark it sold here?" with **Yes, mark sold** / **Not this item**. Yes runs the Sold-here cascade and records the price, the ship-by date and the label that came with it. Not this item deletes that label. Other rows have **Open it**, which opens that email in Cody's own Gmail by its Message-ID, plus **Done** or **OK**. All buttons are protected links.
- **Mail setup** now shows a second form, **Marketplace inbox**. Cody saves a separate Gmail app password, so it can be revoked without touching site mail. It is kept like the sending one: a file in the secrets folder, never shown again. The site tests the login before saving, and **Turn off the inbox** deletes it. If Gmail later refuses the password, the front desk shows "Marketplace emails stopped: renew the inbox app password" with a Renew button.
- **When switched on**, mail from more than 3 days before the switch-on is recorded but not shown, so old news doesn't flood the front desk.
- `ishop-inbox.timer` runs every 10 minutes (installed; it logs "Off" until switched on). Commands: `ishop:inbox-check`, `ishop:inbox-preview --days=30` (reads and shows, stores and changes nothing), `ishop:inbox-switch on|off`. "Needs you now" gets rows from other modules through a new hook, `hook_ishop_needs`; the morning digest picks them up too.
- MIME parsing: zbateson/mail-mime-parser 4.0.6.
